# План разработки Telegram-бота-напоминалки

Этот документ описывает план разработки Telegram-бота, функциональность которого аналогична Microsoft To Do: создание, управление и напоминание о задачах.

## 1. Технический стек

На основе ваших предпочтений был выбран следующий стек технологий:

*   **Язык программирования:** Python
*   **Библиотека для Telegram:** `python-telegram-bot` (v20+)
*   **База данных:** SQLite
*   **Планировщик задач:** `APScheduler`
*   **Среда выполнения:** Запуск на облачном сервере (рекомендуется для постоянной работы)

## 2. Архитектура проекта

Проект будет состоять из нескольких основных компонентов:

*   **`bot.py`:** Главный модуль, который инициализирует бота, обрабатывает команды и сообщения от пользователей.
*   **`database.py`:** Модуль для работы с базой данных. Будет отвечать за создание таблиц, добавление, чтение, обновление и удаление задач.
*   **`scheduler.py`:** Модуль для настройки и управления расписанием проверки напоминаний с помощью `APScheduler`.
*   **`config.py`:** Файл для хранения конфигурационных данных (например, токен бота, путь к базе данных).

## 3. Функциональные требования (Что должен уметь бот)

### Основные команды

*   `/start` и `/help`: Отправить приветственное сообщение и список доступных команд.
*   `/add <описание> [дата время]`: Добавить новую задачу. Пользователь может указать описание и, опционально, дату и время для напоминания.
*   `/list`: Показать список всех активных задач.
*   `/done <номер>`: Отметить задачу как выполненную (удалить из списка активных).
*   `/remind <номер> <дата время>`: Установить или изменить время напоминания для существующей задачи.

### Логика работы

1.  **Добавление задачи:** Пользователь отправляет команду `/add Сделать отчет 2026-05-18 15:00`. Бот парсит сообщение, извлекает описание (`Сделать отчет`) и время (`2026-05-18 15:00`). Эта задача сохраняется в базу данных.
2.  **Планирование напоминаний:** Модуль `scheduler.py` будет постоянно проверять базу данных на наличие задач, для которых наступило время напоминания. Когда такое время наступает, бот отправляет пользователю сообщение: "Напоминаю: Сделать отчет!".
3.  **Управление списком:** Пользователь может в любой момент посмотреть свои задачи (`/list`) или отметить их как выполненные (`/done 1`).

## 4. Этапы разработки

1.  **Настройка окружения:** Создать виртуальное окружение, установить зависимости (`python-telegram-bot`, `apscheduler`, `sqlite3` - обычно входит в стандартную поставку Python).
2.  **Создание структуры проекта:** Создать файлы `bot.py`, `database.py`, `scheduler.py`, `config.py`.
3.  **Реализация базы данных:** Написать код для создания таблицы `tasks` с полями `id`, `user_id`, `description`, `due_date`, `completed`.
4.  **Реализация планировщика:** Настроить `APScheduler` для запуска фоновой задачи, которая каждую минуту проверяет базу данных на предмет истекших дедлайнов.
5.  **Реализация бота:** Написать обработчики для всех команд. Связать их с модулями `database.py` и `scheduler.py`.
6.  **Тестирование:** Протестировать все функции бота вручную.
7.  **Деплой:** Настроить запуск бота на облачном сервере с использованием `systemd` или `screen` для постоянной работы.
