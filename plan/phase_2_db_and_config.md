# План Этапа 2: Настройка конфигурации и базы данных

**Цель:** Создать файл конфигурации и реализовать модуль базы данных с полным набором unit-тестов.

## Задачи

1.  **Создать директорию `plan` и `tests`.**
    *   `plan/`: Для хранения планов каждого этапа.
    *   `tests/`: Для хранения тестовых файлов.

2.  **Создать файл конфигурации `config.py`.**
    *   Добавить переменную `TELEGRAM_BOT_TOKEN` (пока с пустым значением или заглушкой).
    *   Добавить переменную `DATABASE_PATH` со значением `./data/tasks.db`.

3.  **Создать модуль базы данных `database.py`.**
    *   Реализовать функцию `init_db()` для создания таблицы `tasks`.
    *   Реализовать следующие функции:
        *   `add_task(user_id: int, description: str, due_date: str = None) -> int`
        *   `get_tasks(user_id: int) -> list[dict]`
        *   `mark_task_done(task_id: int) -> bool`
        *   `set_reminder(task_id: int, due_date: str) -> bool`

4.  **Написать unit-тесты в `tests/test_database.py`.**
    *   Использовать `unittest` (встроен в Python) или `pytest`.
    *   Для каждого метода в `database.py` написать несколько тестов, включая позитивные и негативные сценарии.
    *   Использовать временную базу данных в памяти (`:memory:`) для изоляции тестов.
    *   **Пример тестов для `add_task`:**
        *   Успешное добавление задачи.
        *   Проверка, что `due_date` сохраняется корректно.
        *   Попытка добавления задачи с некорректными данными (ожидается ошибка).

5.  **Запустить тесты и убедиться, что они проходят.**

## Расписание

*   **День 1:** Создание структуры, `config.py`, `database.py` (реализация).
*   **День 2:** Написание тестов, отладка, запуск тестов.
