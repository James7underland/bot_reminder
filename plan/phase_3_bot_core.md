# План Этапа 3: Реализация ядра бота

**Цель:** Создать основной модуль бота, который будет обрабатывать команды и взаимодействовать с пользователем.

## Задачи

1.  **Создать файл `bot.py`.**
    *   Импортировать необходимые модули: `python-telegram-bot`, `database`, `config`.
    *   Создать обработчики для команд:
        *   `/start` и `/help`: Отправка приветственного сообщения и списка команд.
        *   `/add`: Обработка добавления новой задачи. Разбор аргументов команды (описание и, опционально, дата).
        *   `/list`: Отображение списка активных задач пользователя.
        *   `/done`: Отметка задачи как выполненной.
    *   Инициализировать бота с использованием токена из `config.py`.

2.  **Реализовать функцию `parse_add_command` (в `bot.py`).**
    *   Эта функция будет разбирать текст команды `/add` и извлекать из него описание задачи и, если есть, дату и время.
    *   Использовать регулярные выражения для поиска даты в различных форматах (например, YYYY-MM-DD HH:MM, DD.MM.YYYY и т.д.).
    *   Возвращать кортеж `(description, due_date)`.

3.  **Связать обработчики с функциями.**
    *   Обработчик `/add` должен вызывать `parse_add_command`, а затем `database.add_task`.
    *   Обработчик `/list` должен вызывать `database.get_tasks` и форматировать результат для отправки в Telegram.
    *   Обработчик `/done` должен вызывать `database.mark_task_done`.

4.  **Запустить бота в режиме polling.**
    *   Добавить блок `if __name__ == '__main__':`, который запускает бота.
    *   Использовать `application.run_polling()`.

## Расписание

*   **День 1:** Создание `bot.py`, реализация команд `/start`, `/help`, `/add`.
*   **День 2:** Реализация команд `/list`, `/done`, отладка.


## Ожидаемый результат

*   Файл `bot.py` создан и содержит основную логику бота.
*   Бот запускается и отвечает на команды `/start` и `/help`.
*   Команда `/add` успешно добавляет задачи в базу данных.
*   Команда `/list` выводит список добавленных задач.
*   Обновлен `DEVELOPMENT_LOG.md`. Записано, что тесты временно отложены.
